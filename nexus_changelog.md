# Changelog

### [v1.0.2]
- Fix: Restore Nebula's track no longer goes missing from Growl FM beside this mod. Both play with no patch.
- Fix: other mods that edit the game's audio data at load no longer lose their changes beside this mod.
- Removed: the Restore Nebula Compatibility Patch optional file. It is no longer needed; delete it if you installed it.
- Note: now requires AudioXL 0.4.3 or newer. With an older AudioXL, redscript reports a compile error at launch.

### [Restore Nebula Compatibility Patch v1.0.0] (optional file)
- New optional file. Keeps Restore Nebula's track on Growl FM when this mod is installed. Restore
  Nebula on its own never adds it beside this mod. Needs Restore Nebula and does nothing without
  it. Remove once Restore Nebula carries the fix.

### [v1.0.1]
- Fix: the track played much louder than the rest of Growl FM, and stayed at full volume as you
  walked away from a radio. It now sits at the station's own level and fades with distance like
  every other song.

### [v1.0.0]
- First release. Adds Hardest to Be to 89.7 Growl FM, in normal rotation.
- Plays the full vocal recording already in your game. The mod ships no audio.
- Shows as P.T. Adamczyk, Sora Lion - Hardest to Be, in every language the game ships.
- Works alongside Restore Nebula, which also adds a track to Growl FM.
